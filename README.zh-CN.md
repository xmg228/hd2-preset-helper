# HD2 Preset Helper

[English](README.md) | **简体中文**

HD2 Preset Helper 是一款适用于《绝地潜兵 2》的 Windows 配装预设工具。预设可包含战略配备、强化资源和装备，通过面板保存，再通过面板或自定义快捷键应用。

程序通过屏幕捕获识别游戏界面，再模拟正常的鼠标和键盘操作完成选择。它不会修改游戏文件、向游戏进程注入代码、读取游戏内存或更改网络流量。程序没有联网功能，所有识别和操作均在本地完成。

## 下载与安装

1. 前往 [GitHub Releases](../../releases/latest) 下载最新版本的 ZIP 压缩包。
2. 将压缩包完整解压到一个单独且具有写入权限的文件夹中。
3. 运行 `HD2PresetHelper.exe`。

隐藏面板后程序仍驻留在系统托盘中。左键单击托盘图标重新打开面板，右键选择 **退出** 退出程序。

更新时，先退出程序，再将新文件夹覆盖到原文件夹，保留其中的 `data/`。

卸载时，退出程序并删除程序文件夹即可，已保存的预设也会一并删除。

## 快速开始

1. 在游戏中选好配装。
2. 按 `Ctrl+Shift+Space` 打开面板，选中一个预设，点击 **保存预设**。
3. 以后需要应用时，在战略配备或装备界面打开面板，选择 **应用全部**，或使用预设快捷键（预设 1～6 默认为 `Ctrl+Shift+F7` 至 `Ctrl+Shift+F12`）。

触发保存或应用后，松开所有按键和鼠标按钮。预设快捷键**只应用**，保存请使用面板。

### 预设面板

`Ctrl+Shift+Space` 显示或隐藏面板，Esc 也可隐藏。

鼠标悬浮预览，单击选中，Enter 或双击应用预设。

勾选 **战略配备与强化资源**、**装备** 或两者，选择保存和应用的范围，预设快捷键也使用此范围。保存仅覆盖勾选部分，应用时跳过尚未保存的部分。

### 使用须知

- 配装页面之间的切换使用游戏默认的 `R` 键。
- 保存战略配备要求四个槽位已填满；应用时可以替换已有选择。
- 装备包括头盔、盔甲、披肩、主要武器、次要武器和投掷武器，不保存武器配件或区分同名外观。
- 装备模板可跨分辨率复用，但更改游戏语言后需要重新保存。
- 首次搜索装备时需要学习列表顺序，可能耗时较长；后续搜索会复用缓存。

## 兼容性

程序支持 Windows 10 1903 及更高版本，以及 Windows 11。

目前已在 720p 至 2160p 分辨率下测试窗口模式、无边框窗口模式和全屏模式，其中包括部分非 16:9 分辨率以及 Windows HDR 环境。

使用无边框窗口或全屏模式时，请将游戏分辨率设置为与 Windows 桌面分辨率相同。特殊宽高比、自定义显示缩放比例以及非默认的 HDR UI 亮度尚未经过完整测试。

独占全屏可能在面板取得焦点时最小化，遇到这种情况请使用无边框窗口模式。

## 配置

界面默认跟随系统语言。打开 **设置** 可调整语言、快捷键及其他选项。

面板快捷键全局生效；预设快捷键支持单键，在游戏或面板处于前台时生效。

设置和预设位于程序旁的 `data/` 文件夹，备份该文件夹即可保留。

## 故障排查

快捷键无效时，可在 **设置 → 快捷键** 中检查是否存在冲突。

反馈问题时，请附上 `data/app.log`、游戏分辨率和显示模式、Windows 显示缩放比例、HDR 开启状态，以及出现问题时的游戏界面截图。

## 安全说明

正式版本由 GitHub Actions 自动构建。请仅从本仓库的 Releases 页面下载，并可通过源码、构建记录和 artifact attestation 核对发布文件。

由于程序包含屏幕捕获、全局快捷键和自动输入功能，少数静态安全引擎可能产生启发式误报。

## 从源码构建

安装 Rust 后，在项目根目录运行：

```powershell
cargo build --release --locked
```

生成的可执行文件位于 `target\release\HD2PresetHelper.exe`。
