# HD2 Preset Helper

[English](README.md) | **简体中文**

HD2 Preset Helper 是一款适用于《绝地潜兵 2》的 Windows 配装预设工具。预设可包含战略配备、强化和装备，通过面板保存，再通过面板或自定义快捷键应用。

程序通过屏幕捕获识别游戏界面，再模拟正常的鼠标和键盘操作完成选择。它不会修改游戏文件、向游戏进程注入代码、读取游戏内存或更改网络流量。程序没有联网功能，所有识别和操作均在本地完成。

## 下载与安装

1. 前往 [GitHub Releases](../../releases/latest) 下载最新版本的 ZIP 压缩包。
2. 将压缩包完整解压到一个单独且具有写入权限的文件夹中。
3. 运行 `HD2PresetHelper.exe`。

程序启动时会打开预设面板，隐藏面板后仍驻留在系统托盘中。左键单击托盘图标重新打开面板，右键菜单中的 **Exit** 用于退出程序。

更新时，将新的 `HD2PresetHelper` 文件夹覆盖到原文件夹即可。设置会被保留；如果新版本更改了预设格式，程序会备份旧预设文件并提示重新创建预设。

如需卸载，请先退出程序，然后删除解压出的 `HD2PresetHelper` 文件夹。配置、预设和日志也会随之删除。

## 快速开始

1. 打开游戏的配装主界面，选满四个战略配备，按需选择强化，并穿戴好要保存的装备和武器。
2. 按 `Ctrl+Shift+Space` 打开面板，选中一个预设，勾选两部分，点击 **Save preset** 或按 `Ctrl+S`。松开所有按键和鼠标按钮后开始保存。
3. 以后需要应用时，在任一配装主界面打开面板，选择 **Apply all**，或使用 `Ctrl+Shift+F7` 至 `Ctrl+Shift+F12` 应用预设 1～6。

预设快捷键**只应用，不会保存**。升级时保留原快捷键组合，但不再根据槽位是否填满决定保存／应用。

### 预设面板

`Ctrl+Shift+Space` 可从游戏或桌面切换面板显示，Esc 或切换到其他窗口时隐藏。保存或应用时会切回正在运行的游戏，松开所有按键和鼠标按钮后开始操作。

鼠标悬浮预览，单击、上下方向键或 W/S 选中，Enter 或双击应用预设。使用 **+ New preset** 添加预设，标题旁的编辑和垃圾桶图标用于重命名与删除。

勾选 **Stratagems & Booster**（战备／强化）、**Equipment**（装备）或两者，决定保存和应用的范围。此选择由所有预设共用，重启后保留，快捷键也使用相同范围。**保存会直接覆盖勾选的部分，不另行确认**；未勾选部分保持原样。应用时跳过尚未保存的部分。

### 使用须知

- 从战备或装备主界面开始操作，页面切换使用游戏默认的 `R` 键。
- 保存战备要求四个槽位已填满，仅保存装备时不要求。应用会保留匹配的战备、替换其余战备并填补空槽；按保存顺序应用仅在初始四槽全空时生效。
- 装备包括头盔、护甲、披风、主武器、副武器和投掷物，不保存武器配件或区分同名外观。模板和顺序缓存可跨分辨率复用；更改游戏语言后，请重新保存装备。
- 首次搜索某个装备分类时会完整扫描，可能耗时较长；之后复用学习到的顺序。

## 兼容性

程序支持 Windows 10 1903 及更高版本，以及 Windows 11。

目前已在 720p 至 2160p 分辨率下测试窗口模式、无边框窗口模式和全屏模式，其中包括部分非 16:9 分辨率以及 Windows HDR 环境。

使用无边框窗口或全屏模式时，请将游戏分辨率设置为与 Windows 桌面分辨率相同。特殊宽高比、自定义显示缩放比例以及非默认的 HDR UI 亮度尚未经过完整测试。

独占全屏可能在面板取得焦点时最小化，遇到这种情况请使用无边框窗口模式。

## 配置

打开面板中的 **Settings**：

- **Shortcuts**：设置面板快捷键和各预设的可选快捷键，支持单键。面板快捷键全局生效，预设快捷键在游戏或面板处于前台时生效；面板内优先使用自身的导航键。使用小键盘数字时请开启 Num Lock，避免与 Shift 组合。
- **General**：设置按保存顺序应用、自动准备、保存备选强化，以及面板和状态窗使用的显示器。

设置保存后生效。如需直接编辑文件，请参考 `data/config.toml` 中的注释，修改后重启程序。

所有用户数据均位于程序旁的 `data/` 文件夹，备份整个文件夹即可保留设置和预设。如需重新学习装备顺序，请退出程序后仅删除 `data/equipment-cache.json`。

## 故障排查

如果按下预设快捷键后没有反应，请确认：

- 程序正在系统托盘中运行；
- 游戏停留在稳定显示的配装主界面；
- 游戏或预设面板是当前前台窗口，且未在输入名称或录入快捷键；
- 没有其他程序占用相同的快捷键。

反馈问题时，请附上 `data/app.log`、游戏分辨率和显示模式、Windows 显示缩放比例、HDR 开启状态，以及出现问题时的游戏界面截图。

## 安全说明

正式版本由 GitHub Actions 自动构建。请仅从本仓库的 Releases 页面下载，并可通过源码、构建记录和 artifact attestation 核对发布文件。

由于程序包含屏幕捕获、全局快捷键和自动输入功能，少数静态安全引擎可能产生启发式误报。

## 从源码构建

普通用户建议使用 GitHub Releases 中的预构建压缩包。如需自行构建，请安装当前稳定版 Rust 工具链，在项目根目录运行：

```powershell
cargo build --release --locked
```

生成的可执行文件位于 `target\release\HD2PresetHelper.exe`。
