# HD2 Preset Helper

[English](README.md) | **简体中文**

HD2 Preset Helper 是一款适用于《绝地潜兵 2》的 Windows 配装预设工具。它可以直接在游戏的配装界面保存四个战略配备和一个可选强化，并通过快捷键快速应用已经保存的预设。

程序通过屏幕捕获识别游戏界面，再模拟正常的鼠标和键盘操作完成选择。它不会修改游戏文件、向游戏进程注入代码、读取游戏内存或更改网络流量。程序没有联网功能，所有识别和操作均在本地完成。

> [!WARNING]
> **目前暂不支持替换战略配备图标的 Mod。** 如果原版战略配备图标被替换，程序将无法正确识别。
>
> 目前正在尝试寻找兼容修改后图标的方案。


## 下载与安装

1. 前往 [GitHub Releases](../../releases/latest) 下载最新版本的 ZIP 压缩包。
2. 将压缩包完整解压到一个单独且具有写入权限的文件夹中。
3. 运行 `HD2PresetHelper.exe`。

程序启动后会驻留在系统托盘中。需要退出时，右键单击托盘图标并选择 **Exit**。

## 快速开始

默认预设快捷键为 `Ctrl+Shift+F7` 至 `Ctrl+Shift+F12`，分别对应预设槽位 1～6。

1. 打开游戏的配装主界面，选满四个战略配备，并按需选择一个强化。
2. 按住 `Ctrl+Shift` 显示预设浮窗。
3. 按一下 `F7`～`F12` 后松开所有按键，程序随后会将当前配装保存到对应的预设槽位。
4. 以后需要应用该预设时，回到配装主界面，清空四个战略配备槽位，再按下相同的快捷键组合。

| 当前配装状态 | 执行结果 |
| --- | --- |
| 四个战略配备槽位均已选择 | 保存或覆盖对应预设 |
| 四个战略配备槽位均为空 | 应用对应预设 |
| 只选择了部分战略配备 | 拒绝执行，不修改当前配装 |

强化为可选项。保存预设时，当前选择的强化会与四个战略配备一并保存。

## 兼容性

程序支持 Windows 10 1903 及更高版本，以及 Windows 11。

目前已在 720p 至 2160p 分辨率下测试窗口模式、无边框窗口模式和全屏模式，其中包括部分非 16:9 分辨率以及 Windows HDR 环境。

使用无边框窗口或全屏模式时，请将游戏分辨率设置为与 Windows 桌面分辨率相同。特殊宽高比、自定义显示缩放比例以及非默认的 HDR UI 亮度尚未经过完整测试。

## 配置

请将程序放在具有写入权限的文件夹中。运行时会使用以下文件：

- `data/config.toml`：快捷键、预设浮窗及其他可选设置；
- `data/presets.json`：已经保存的预设；
- `data/app.log`：最近一次启动产生的诊断日志。

如果默认快捷键与其他程序或系统快捷键冲突，可以在 `data/config.toml` 中修改。预设通常直接通过游戏内操作保存，不需要手动编辑 `data/presets.json`。

## 故障排查

如果按下预设快捷键后没有反应，请确认：

- 程序正在系统托盘中运行；
- 游戏停留在稳定显示的配装主界面；
- 四个战略配备槽位均已选择或均为空；
- 《绝地潜兵 2》是当前前台窗口；
- 没有其他程序占用相同的快捷键。

反馈问题时，请附上 `data/app.log`、游戏分辨率和显示模式、Windows 显示缩放比例、HDR 开启状态，以及出现问题时的游戏界面截图。

## 安全说明

正式版本由 GitHub Actions 自动构建。请仅从本仓库的 Releases 页面下载，并可通过源码、构建记录和 artifact attestation 核对发布文件。

由于程序包含屏幕捕获、全局快捷键和自动输入功能，少数静态安全引擎可能产生启发式误报。

## 从源码构建

普通用户建议直接使用 GitHub Releases 中提供的预构建压缩包。

如需自行构建，请安装当前稳定版 Rust 工具链，然后在项目根目录运行：

```powershell
cargo build --release --locked
```

生成的可执行文件位于：

```text
target\release\HD2PresetHelper.exe
```
